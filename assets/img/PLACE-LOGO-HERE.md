# Drop the ICAI logo here

Save the official ICAI logo in **this folder** with the exact filename:

```
assets/img/icai-logo.png
```

No code changes are needed — the splash and closing screens pick it up
automatically and frame it inside a light "seal" medallion (so a logo on a
white or transparent background still looks premium on the dark theme).

- Recommended: a square-ish PNG, at least 400×400 px. Transparent background is
  ideal, but a white background works too (the medallion is light).
- If the file is missing, the app shows a tidy "ICAI" text seal instead of a
  broken image — so nothing looks broken before you add it.

You can also use a `.jpg`/`.svg` — if so, update the two `src="assets/img/icai-logo.png"`
references in `index.html` to match your filename.
